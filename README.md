# 👑 İmparatorluk

Total War tarzı gerçek zamanlı taktik savaş + EU4 / Victoria 3 / Age of History esintili sıra tabanlı devlet yönetimi.

## Özellikler
- **Strateji katmanı (sıra tabanlı):** vergi, ferman, kanunlar (Vic3), ilgi grupları, binalar, isyan riski
- **EU4 mekanikleri:** 3 nüfuz puanı (idari/diplomatik/askeri), çekirdek sistemi, işgal & barış masası, savaş skoru, koalisyon
- **Diplomasi:** hediye, ticaret, ittifak, savaş ilanı, beyaz/galibiyet/mağlubiyet barışı
- **Taktik savaş (gerçek zamanlı):** piyade, okçu, süvari, topçu — moral, kaçış, arazi bonusu, ordu tecrübe seviyesi
- **Ses:** AI ile üretilmiş müzik ve efektler
- Seçimli olaylar, kaydet/yükle (localStorage), mobil + responsive

## Çalıştırma
```bash
npm install
npm run build   # dist/ çıktısı
```

> Not: `public/img` ve `public/ses` altındaki AI ile üretilmiş medya dosyaları repoya dahil değildir.
